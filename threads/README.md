# Threads голосом владельца: лента (t88) и радар LEADS (t82)

Две команды на одном профиле голоса `voice.md` (заполняется по памяти fukkality-threads-voice):

- `feed` собирает на день 6–8 своих постов из реальных историй владельца;
- `radar` ищет в Threads людей, которым нужно то, что делает владелец, и готовит им ответ;
  `reply N` отправляет этот ответ в одно касание.

Тексты пишет Gemini, каждый текст проходит детерминированный фильтр AI-признаков.
Зависимостей нет, только стандартная библиотека Python 3.10+.

## Лента (t88)

1. Из `stories.jsonl` берутся свежие неиспользованные истории без видео, с запасом в две штуки.
2. Gemini пишет по одному посту на историю голосом из `voice.md`, только по фактам истории.
3. Фильтр (`threadskit/ai_filter.py`) проверяет каждый пост: штампы вроде «давайте разберёмся»,
   «не просто X, а Y», «в мире, где», длинное тире, списки, markdown, хэштеги, эмодзи, лимит 500 символов,
   фразы из раздела «Никогда не пишу». Ещё он сверяет числа и ссылки: того, чего нет в истории, в посте быть не должно.
4. Пост с замечаниями один раз уходит Gemini на переписывание. Не прошёл и после этого, попадает в `rejected`.
5. Прошедшие посты раскладываются по дню с 9:00 до 22:00, план пишется в `out/feed-<дата>.json`.
   Истории, по которым пост вошёл в план, отмечаются в `state/used.json` и больше не повторяются.

Если годных постов меньше шести, план всё равно сохраняется с предупреждением: добивать ленту выдумкой нельзя.

Формат истории, одна на строку:

```json
{"id": "2026-10-20-client", "date": "2026-10-20", "media": "text", "text": "Что реально произошло"}
```

`media: "video"` пропускается.

## Радар LEADS (t82)

Радар сужен до одной категории, LEADS: автор поста сам ищет исполнителя, просит посоветовать,
кого нанять, или ищет решение задачи, которую закрывает предложение владельца.
Реклама, такие же исполнители в поиске клиентов, шутки и новости лидами не считаются.

1. По каждому запросу из `radar.json` Threads API (`keyword_search`, `RECENT`) отдаёт посты
   не старше `max_age_hours`. Свои посты, повторы и уже оценённые посты отбрасываются.
2. Gemini пачками по 20 оценивает каждый пост: лид или нет, вероятность покупки 0–100, почему,
   и для лида пишет короткий ответ голосом владельца. Текст чужих постов для модели только данные, не инструкции.
3. Лиды ниже `min_score` отбрасываются. Ответ лиду проходит тот же фильтр AI-признаков; числа и ссылки в нём
   должны быть из поста или из `offer`, так что чужой пост не подсунет в ответ свою ссылку. Не прошёл после одного переписывания, лид остаётся в дайджесте без готового ответа.
4. Дайджест пишется в `out/radar-<дата-время>.md`: ссылка на пост, цитата, почему это лид, ответ и команда отправки.
   Лиды копятся в `state/leads.json` под постоянными номерами, оценённые посты помнятся 30 дней в `state/radar_seen.json`.
5. `python -m threadskit reply 3` публикует готовый ответ лиду №3 в комментарии к его посту.
   Свой текст: `reply 3 --text "..."`, посмотреть без отправки: `reply 3 --dry-run`.
   Дважды одному лиду ответить нельзя.

`radar.json`:

```json
{
  "offer": "Что делаю, для кого и какую задачу закрываю",
  "queries": ["ищу дизайнера", "посоветуйте подрядчика"],
  "min_score": 70,
  "max_age_hours": 48,
  "username": "fukkality"
}
```

Спецификация радара `docs/superpowers/specs/2026-10-24-threads-radar-design.md` в этот репозиторий
не попала; радар собран по постановке задачи t82, суженной до LEADS.

## Запуск

```bash
cp voice.example.md voice.md              # заполнить по памяти fukkality-threads-voice
cp stories.example.jsonl stories.jsonl    # заменить своими реальными историями
cp radar.example.json radar.json          # своё предложение и поисковые запросы
export GEMINI_API_KEY=...                 # ключ Google AI Studio
export THREADS_ACCESS_TOKEN=...           # для radar и reply: threads_basic, threads_keyword_search,
                                          # threads_content_publish, threads_manage_replies

python -m threadskit feed --date 2026-10-26 --per-day 7
python -m threadskit radar
python -m threadskit reply 1
```

Модель по умолчанию `gemini-3.8-flash`, другую можно задать через `GEMINI_MODEL`.
Без одобренного Meta права `threads_keyword_search` поиск находит только посты самого владельца.

`voice.md`, `stories.jsonl`, `radar.json`, `out/` и `state/` в git не попадают: репозиторий публичный.
