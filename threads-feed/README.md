# Лента Threads голосом владельца (t88)

Каждый день собирает 6–8 своих постов из реальных историй владельца.
Тексты пишет Claude, затем каждый пост проходит фильтр AI-признаков.
Видео в ленту не берём, выдуманных историй тоже.

## Как это работает

1. Из `stories.jsonl` берутся свежие неиспользованные истории без видео (с запасом в две штуки).
2. Claude пишет по одному посту на историю голосом из `voice.md`.
3. Фильтр (`feed/ai_filter.py`) проверяет каждый пост: штампы вроде «давайте разберёмся» и «не просто X, а Y»,
   длинное тире, списки, markdown, хэштеги, эмодзи, лимит 500 символов, фразы из раздела «Никогда не пишу».
   Ещё он сверяет числа: цифр, которых нет в истории, в посте быть не должно.
4. Пост с замечаниями один раз уходит Claude на переписывание. Не прошёл и после этого, попадает в `rejected`.
5. Прошедшие посты раскладываются по дню с 9:00 до 22:00, план пишется в `out/<дата>.json`.
   Истории, по которым пост вошёл в план, отмечаются в `state/used.json` и больше не повторяются.

Если годных постов меньше шести, план всё равно сохраняется с предупреждением: добивать ленту выдумкой нельзя.

## Запуск

```bash
pip install -r requirements.txt
cp voice.example.md voice.md            # заполнить по памяти fukkality-threads-voice
cp stories.example.jsonl stories.jsonl  # заменить своими историями
export ANTHROPIC_API_KEY=...            # или `ant auth login`
python -m feed --date 2026-10-25 --per-day 7
```

`voice.md`, `stories.jsonl`, `out/` и `state/` в git не попадают: репозиторий публичный.

Формат истории, одна на строку:

```json
{"id": "2026-10-20-client", "date": "2026-10-20", "media": "text", "text": "Что реально произошло"}
```

`media: "video"` пропускается.
